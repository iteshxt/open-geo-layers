# open-geo-layers

Working name: **MapForge**.

A personal hobby After Effects extension that recreates, feature for feature, the map-animation workflow of GEOlayers 3. It is a clean-room build from public documentation only. No code, assets or branding come from the original.

## Where things are

| File | What it is |
|---|---|
| [docs/FEATURE_SPEC.md](docs/FEATURE_SPEC.md) | 444 requirements with acceptance checks. Each ID matches the inventory, so we can track parity. |
| [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) | Platform decision (CEP + ExtendScript), modules, tech stack, Linux dev and testing, milestones M0–M10 |
| [docs/OPEN_QUESTIONS.md](docs/OPEN_QUESTIONS.md) | 55 open questions, each with a recommended default |
| [docs/HANDS_ON_SESSION_1.md](docs/HANDS_ON_SESSION_1.md) | Checklist for the first hands-on observation session on Windows with the original's trial (rules, setup, 34 tasks by priority, output format) |
| [research/feature-inventory.md](research/feature-inventory.md) | Master list of the original's features: 444 items, each tagged SOURCED or INFERRED |
| [research/notes/](research/notes/) | Raw research notes by track: docs, videos, community, providers, AE platform, web app |
| [research/sources/](research/sources/) | Public source material: official help, full changelog, the vendor's public example scripts |

## Ground rules

- Clean-room only. Never download, unpack or decompile the original (ZXP, trial, examples zip, pirated copies).
- Use our own name, icons, styles and template designs, built to the same behaviour.
- "Done" means every ID in the feature inventory is implemented and checked.
