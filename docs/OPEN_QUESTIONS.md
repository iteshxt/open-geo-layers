# MapForge — Open Questions

Things only the user can decide, or that need hands-on access to the original extension running in After Effects (Windows/macOS). Each question has a **recommended default**; the build proceeds with the default until the user answers. IDs refer to `research/feature-inventory.md` and `docs/FEATURE_SPEC.md`.

"Hands-on" means the user runs the original (a licence they own or a trial) and reports what they see: screenshots, tooltip text, dialog text, layer names, effect names. We never open, unpack or inspect the original's files.

Priority: **P1** blocks a milestone's design; **P2** affects exact parity of details; **P3** nice to know.

**EBE update (2026-11-19):** the transcript of "GEOlayers 3 for Beginners: Every Button Explained" (inventory source EBE) resolved or narrowed Q-10, Q-16, Q-18, Q-19, Q-24, Q-29, Q-32, Q-33, Q-35, Q-36, Q-37, Q-38 and Q-39. Those rows keep their question and add "Resolved (EBE)" or "Narrowed (EBE)"; their recommended defaults are updated. A verification pass the same day softened several EBE readings (narration order is not on-screen order; icon matches are inferred) and added Q-50 to Q-55. The first hands-on session checklist is `docs/HANDS_ON_SESSION_1.md`.
